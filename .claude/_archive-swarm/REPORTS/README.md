# REPORTS/ — Reportes finales por frente

Cada frente deja aqui su reporte al terminar una ola.

## Formato de nombre

```
{ola}-{frente}-{fecha}.md
```

Ejemplo: `ola2-frente-back-2026-04-10.md`

## Contenido esperado

```markdown
# Reporte {frente} — Ola {N}

## Archivos creados
- ruta/archivo.ts (N lineas) — descripcion

## Archivos modificados
- ruta/archivo.ts (+N/-M lineas) — que cambio

## Verificacion
- [ ] TSC: 0 errores
- [ ] Lint: 0 errores en archivos tocados
- [ ] Tests: N/N verdes

## Items del roadmap completados
- #X titulo — done
- #Y titulo — done

## Notas para el orchestrator
- (cualquier dependencia no resuelta, bloqueo, o sugerencia)
```
