# Forks, worktrees y carriles en paralelo

> Sacado de `.claude/rules/agentic-style.md` el 02-11-2026 (Brandon: «reglas más cortas»): se lee solo al lanzar 2+ ayudantes que editan, un fork o un workflow con carriles.

- Un fork hereda TODA tu meta: si el hilo principal sigue mutando el mismo estado, decile «NO continúes ninguna otra tarea, sólo esto». Redirigir con `SendMessage`, nunca un fork nuevo con el mismo `name` (memoria `fork-tool-anomalous-response`).
- Nunca `isolation: "worktree"`: en esta rama larga branchea de una base vieja y se pierde lógica (2026-08-03). Trabajo grande = agentes con archivos disjuntos sobre el checkout principal.
- Revisores (`reviewer`/`security`) en un workflow: prompt con «≤40 llamadas» y reporte final en TEXTO. Con `schema` sobre diffs de 30+ archivos, 5 de 9 terminaron a los 70-100 turnos sin devolver nada (08-10); los mismos como `Agent` con tope respondieron en 3-6 min.
- Commit de un agente con otros en paralelo: `npm run test:guardianes` antes y `scripts/commit-carril.sh -F <msg> -- <sus archivos>` (= `git commit` en fila con `flock`: 26-10 dos choques con `index.lock`). Sin `-- paths` se lleva lo que otro dejó staged (08-10: un commit arrastró 18 archivos ajenos) y un guardián rojo de un archivo ajeno tumba el commit.
- Workflow con carriles que comparten tipos: los commits van en una fase final DESPUÉS de que todos los carriles cierren (08-10: el commit de un carril terminado cayó por el tsc rojo de otro a medio construir y hubo que reintentarlo a mano).
- Carriles en paralelo: cada uno con su `scratchpad/<carril>/` en el prompt (08-10: 3 de 5 carriles perdieron una corrida porque otro pisó su `medir.js`) y `npm run test:guardianes` antes del primer commit del lote — y CADA carril lo corre antes de reportar (5 s): los guardianes escanean el disco, así que un ⓘ en un `<label>` o una ruta sin `permisoAdelantos` de un carril tumba el commit de OTRO (23-10: 3 commits caídos así).
- Con 2+ carriles vivos, el carril NO corre `npm run typecheck` completo: el LSP post-Edit NO le llega a un subagente (medido 22-10 y 23-10: un error pasó sin aviso), así que usa `scripts/tsc-acotado.sh <sus archivos>` (≈7 s; hereda el tsconfig del repo — 02-11 un tsconfig recortado a mano sin `extends` dio «0 errores» con 5 íconos que el DS no exportaba) + `npx vitest run <sus tests>` (no `related`: 30-10, con 3 carriles y 2 sesiones vivas `related` pasó los 10 min con la carga en 30-40; `run` de sus tests, <1 min). El hilo principal hace los commits en la fase final. El typecheck completo lo corre el hilo principal una vez, con los carriles cerrados (19-10: 7 corridas murieron con exit 137 porque el dev server ocupaba 6,3 GB del tope de 13 GB; si muere igual, reiniciar el dev server y relanzarlo con `nohup npm run dev > /tmp/dev-server.log 2>&1 &`: el `dev-with-canary` no se levanta solo).
- Con agentes en paralelo, antes de CREAR un archivo: `ls` la ruta. Un Write pisa lo que otro agente creó y todavía no está en git (03-10: el backend del croquis borró `planta-croquis.ts` del frontend; se salvó desde la transcripción). Contrato de tipos compartido = escribirlo y confirmarlo ANTES de lanzar a los dos.
